# Road-to-NextWind

## Just some random projects to practice/learn Next.js + taildiwnd

- Tres en linea
  - Just the example project on react.dev/learn
  - It's a tic tac toe, with movements memory.
  - Added some coloring and formating for "bonus".
  - Plain React, no framework.

- push_swap-visualizer
  - Just a visualizer for the push_swap 42 project.
  - Shows both stacks (A and B) and animates each move step by step.
  - Contains [files for testing](./push_swap-visualizer/testing_files) and a script to run with your own push_swap (Or try mine).

- rpn-calculator
  - A Reverse Polish Notation (RPN) calculator.
  - Animates the stack: numbers push in and merge into the result.
  - Built with Next.js + Tailwind.
